Velmora Statistics — the national statistics site of the fictional Republic of Velmora. Population, economy, health, education, environment and regions, with hand-drawn SVG charts, a working indicator search, year pickers, a population projector, an inflation adjuster, sortable region tables and downloadable CSVs. A static site under `app/` with no build step and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the overview, and every topic page, works on desktop and on a phone.
